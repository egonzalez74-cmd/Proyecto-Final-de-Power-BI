# Proyecto Final - Power BI
Este proyecto consiste en el desarrollo de un dashboard interactivo en Power BI utilizando la base de datos Northwind, con el objetivo de analizar información relacionada con ventas, productos, categorías y distribución geográfica de clientes.
A través de visualizaciones dinámicas y herramientas de análisis, se busca facilitar la interpretación de datos.

---

## Objetivos 

- Analizar el comportamiento de ventas.
- Identificar los productos más vendidos.
- Visualizar la distribución geográfica de clientes.
- Evaluar ventas por año y categoría.
- Aplicar herramientas de visualización y modelado de datos en Power BI.

---

# Herramientas Utilizadas

- **Power BI Desktop**
- **Base de datos Northwind**
- **Excel / CSV**
- **DAX (Data Analysis Expressions)**
